📘 Követelményspecifikáció – CutCalculator rendszer (Anyagszükséglet számítás + Order kezelés)

🎯 Cél

A rendszer feladata, hogy a megrendelésekből kiszámolja a gyártáshoz
szükséges anyagokat (vágási méretek és szerelési darabok), a
ProductDefinition szabályok alapján.
Az eredmény egy auditálható, aggregált gyártási lista, amely lefedi a
teljes folyamatot: megrendelés → számítás → aggregálás → audit → preview
→ export → gyártás.

------------------------------------------------------------------------

🧩 Követelmények

Adatmodellek

-   MaterialMaster (globális törzs) 🧱
    -   Minden alapanyag (tok, tengely, pálca, szövet, rugó, szerelék,
        csőmotor).
    -   Mezők: id, name, type, size, color, weight, gép, RAL/HEX
        színkód.
-   ProductDefinition (globális táblázat) 📦
    -   Terméktípusokhoz levonási szabályok és szerelékek.
    -   Példa: Tetőtéri rugós roletta → tengely -15 mm, pálca -10 mm, 2
        db rugó.
    -   Verziózás: új szabályok új rendelésekhez, régiek auditban
        megmaradnak.
-   NeedRule (kapcsolótábla) 🔗
    -   Kapcsolat ProductDefinition ↔ MaterialMaster között.
    -   Mezők: id, productId, materialId.
-   NeedCalculation (számítási mód) 🧮
    -   Számítási mód egy NeedRule‑hoz.
    -   Mezők: needRuleId, mode (pl. “falc”, “glass”, “fabric”,
        “manufacturing”), formula (pl. “w-15”, “fixed:2”).
-   Order (megrendelés) 📑
    -   OrderHeader: tételszám, megrendelő neve, dátum, státusz.
    -   OrderLine: productId, width, height, quantity, color,
        handlerSide.
-   NeedResult (runtime) 📊
    -   Számítás eredménye.
    -   Mezők: materialId, lengthMm, pieces, mode, (opcionálisan areaMm2
        szövethez).
-   AuditEntry 🕵️
    -   Audit log: hiányzó szabály, hibás formula, hiányzó anyag.

------------------------------------------------------------------------

Számítási logika

-   Méretre vágott elemek: szélesség − levonás.
-   Fix darabos elemek: darabszám × fix mennyiség.
-   Aggregálás: azonos ügyfél + azonos termék + azonos szín →
    összevonás.
-   Audit: jelzés, ha hiányzik szabály, anyag vagy formula.

------------------------------------------------------------------------

UI követelmények

-   Order entry UI 🖊️
    -   Megrendelő neve → autocomplete.
    -   Tételszám → automatikusan növekvő.
    -   Termék kód → dropdown a ProductDefinition táblából.
    -   Méret + darabszám → kötelező mezők, validációval.
    -   Szín → autocomplete + színkocka.
    -   HandlerSide → bal/jobb választó.
    -   Dátum → automatikusan kitöltődik, módosítható.
-   Anyagszükséglet lista (preview) 👀
    -   Real‑time számítás: azonnal látszik, milyen anyag kell.
    -   Aggregálás: összevonás azonos ügyfél + termék + szín esetén.
    -   Audit jelzés: ha hiányzik szabály, figyelmeztet.
    -   Export: CSV/Excel gyártási lista.

------------------------------------------------------------------------

Extra kényelmi funkciók

-   Megrendelő emlékezet: több termék esetén automatikusan kitölti a
    nevet és színt.
-   Szűrés és keresés: gyors keresés a felvitt tételek között.
-   Export: teljes anyagszükséglet lista kimenthető.
