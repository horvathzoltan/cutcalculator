⭐ ÖSSZEFOGLALT TERV

Csak a két maradék fókuszpontra

(ConnectionCrudMixin → protected, MatrixValidator integráció)

------------------------------------------------------------------------

🎯 1. ConnectionCrudMixin → protected

🔍 A vizsgálat célja

Megállapítani, hogy:

-   valóban szükséges‑e még bármilyen beavatkozás,
-   vagy a probléma már megszűnt, csak a státusz maradt „Folyamatban”.

🔎 Ellenőrző kérdések (audit során)

1.  Használja‑e bármely registry a raw CRUD API‑t?
    -   keresés: insertRaw, removeRaw, storeAddImpl, storeRemovePairImpl
        közvetlen hívása
2.  Van‑e olyan UI vagy Presenter, amely közvetlenül hív engine‑szintű
    write API‑t?
    -   keresés: .add(, .removeInternal(, .updateInternal(
3.  A ConnectionCrudMixin ténylegesen szükséges‑e még?
    -   van‑e olyan registry, amely a mixinre épít
4.  A kommentelt mixin okoz‑e build‑ vagy include‑zajt?
    -   felesleges include, félbehagyott kód
5.  A RegistryEngineBase friend‑listájában maradt‑e felesleges friend?

📌 Ha a vizsgálat eredménye: „nincs probléma”

→ A pont lezárható, státusz: Kész
→ A mixin törölhető vagy archiválható

📌 Ha a vizsgálat eredménye: „van teendő”

A megoldás három lépésből áll:

1) A ConnectionCrudMixin végleges eltávolítása vagy protected‑dé tétele

-   törölni a kommentelt blokkot
-   vagy protected szintre tenni, ha később kellhet

2) A RegistryEngineBase friend‑listájának tisztítása

-   eltávolítani a felesleges friend deklarációkat

3) Ellenőrizni, hogy minden registry kizárólag workflow API‑t használ

-   NeedRuleRegistry → OK
-   NeedCalculationDetailRegistry → OK
-   ProductRegistry / MaterialRegistry → ellenőrizni

------------------------------------------------------------------------

🎯 2. MatrixValidator + Detail torony összehangolása

🔍 A vizsgálat célja

Megállapítani, hogy:

-   a MatrixValidator valóban hiányosan integrált‑e,
-   vagy csak a státusz maradt „Folyamatban”.

🔎 Ellenőrző kérdések (audit során)

1.  A Presenter használja‑e a MatrixValidator‑t?
    -   keresés: MatrixValidator:: a Presenterben
2.  A RepositoryOverlayWidget támogatja‑e a mátrix‑állapotot?
    -   van‑e MatrixIncomplete vagy hasonló state
3.  A UI mutat‑e bármilyen mátrix‑komplettség jelzést?
    -   toolbar overlay ikon
4.  Van‑e MatrixValidatorTester?
    -   teszteli‑e:
        -   validateMode
        -   validateProduct
        -   validateAll
        -   isCalculationMatrixComplete
        -   isProductMatrixComplete
5.  A NeedCalculationDetailRegistry domain szabályai összhangban
    vannak‑e a validatorral?
    -   formula validáció
    -   duplicate szabály
    -   materialId / calcId ellenőrzés

📌 Ha a vizsgálat eredménye: „nincs probléma”

→ A pont lezárható, státusz: Kész

📌 Ha a vizsgálat eredménye: „van teendő”

A megoldás négy lépésből áll:

1) Presenter integráció

MaterialRequirementsPresenter::refreshOverlayOnly()
→ egészítsük ki:

    bool complete = MatrixValidator::isProductMatrixComplete(_treeManager->currentProductId());
    _status->setMatrixState(complete);

2) Overlay widget bővítése

-   új state: MatrixIncomplete
-   új ikon: pl. „⚠️” vagy „🧩”

3) UI vizualizáció

-   tooltip: „Hiányzó calculation detail”
-   overlay ikon a toolbaron

4) MatrixValidatorTester létrehozása

Tesztelje:

-   validateMode
-   validateProduct
-   validateAll
-   isCalculationMatrixComplete
-   isProductMatrixComplete
