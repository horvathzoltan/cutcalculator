⭐ 1. FÁZIS — Order domain bevezetése (2–3 nap)

A legnagyobb falat, de szépen szeletelhető.

1.1. OrderHeader + OrderLine + OrderItem + Order domain modellek

Fájlok: - orders/model/order_header.h - orders/model/order_line.h -
orders/model/order_item.h - orders/model/order.h

Mezők: - OrderHeader: customerName, orderDate, defaultColor,
defaultHandlerSide, defaultExternalPrefix, note, status
- OrderLine: productId, width, height, qty, overrides (color, handler,
externalId)
- OrderItem: id + OrderLine + qty
- Order: id + header + lines

Al‑lépések: - 1.1.a – OrderHeader struct
- 1.1.b – OrderLine struct
- 1.1.c – OrderItem + Order összerakása
- 1.1.d – UUID generálás, validációk

------------------------------------------------------------------------

1.2. OrderRepository (CSV vagy DB)

Háromfázisú import/export: - Convert → Validate → Build → Assemble

Al‑lépések: - 1.2.a – Row → Convert
- 1.2.b – Validate
- 1.2.c – Build
- 1.2.d – Assemble

------------------------------------------------------------------------

1.3. OrderService

-   CRUD workflow
-   Default értékek örökítése
-   ExternalId prefix kezelése
-   OrderHeader + OrderLine konzisztencia ellenőrzés

------------------------------------------------------------------------

1.4. OrderQuery

-   keresés név, dátum, státusz, externalId alapján

------------------------------------------------------------------------

1.5. StringCache (autocomplete)

-   customerName
-   city
-   externalId prefix
-   colorName
-   handlerSide

------------------------------------------------------------------------

1.6. OrderWorkbench UI (v1 skeleton)

-   OrderHeaderPanel
-   OrderLineTable
-   Save/Load
-   alap layout (BOMWorkbench mintájára)

Eredmény:
Van egy működő Order domain + UI, még NeedCalculator integráció nélkül.

------------------------------------------------------------------------

⭐ 2. FÁZIS — Order → Calculation pipeline integráció (1–2 nap)

2.1. Domain Order → technikai Order konverzió

-   OrderHeader + OrderLine → OrderNeedBuilder::OrderItem
-   default értékek örökítése
-   externalId prefix + sorszám generálás

Al‑lépések: - 2.1.a – OrderHeader + OrderLine → OrderItem konverzió
- 2.1.b – öröklés (color, handler, externalId)
- 2.1.c – externalId példányosítás: X1 → X1.1, X1.2, X1.3…

------------------------------------------------------------------------

2.2. OrderNeedBuilder módosítása

-   új Order struktúra támogatása
-   externalRef generálás (ha nem WorksheetBuilderben csináljuk)

------------------------------------------------------------------------

2.3. Tesztek

-   RolettaCalculationTester továbbra is fusson
-   új Order tesztek (öröklés, externalId, qty)

Eredmény:
A perzisztens Orderből már tudunk OrderNeed‑et generálni.

------------------------------------------------------------------------

⭐ 3. FÁZIS — Worksheet pipeline stabilizálása (1 nap)

Ez a rész hiányzott az új roadmapből, most visszakerült.

3.1. WorksheetNeed pontosítása

-   WorksheetNeed = OrderNeed „gyártási nézete”
-   worksheetId = orderId (átmeneti, WorkOrderNeed után változik)

3.2. WorksheetBuilder frissítése

-   externalRef generálás stratégia véglegesítése
    -   OrderNeedBuilder vagy WorksheetBuilder?
-   aggregálási kulcsok dokumentálása
    -   Cutting: barcode + length + handlerSide
    -   Kitting: barcode

3.3. Worksheet UI (később)

Eredmény:
Egy Orderből teljes gyártási lista készül.

------------------------------------------------------------------------
