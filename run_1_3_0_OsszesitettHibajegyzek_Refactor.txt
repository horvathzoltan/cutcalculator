⭐ PATCH 23 – OrderItem műveletek (Add / Edit / Delete)

Auditálható, pontonkénti fejlesztési terv

------------------------------------------------------------------------

1) Cél és scope

A jelenlegi OrderItemTable:

-   csak megjelenít
-   csak szerkeszt
-   nem tud új sort felvenni
-   nem tud sort törölni
-   nincs toolbar
-   nincs Presenter oldali támogatás

A PATCH 23 célja:

-   Add Item – új üres OrderItem hozzáadása
-   Delete Item – kijelölt sor törlése
-   Edit Item – már működik, marad
-   Auto‑empty row – mindig legyen legalul egy üres sor
-   Toolbar – Add / Delete gombokkal
-   Presenter integráció – domain műveletekhez kötve
-   OrderManager integráció – új OrderItem létrehozása, törlése

------------------------------------------------------------------------

2) UX / UI döntések

Toolbar gombok:

-   ➕ Add item
-   ❌ Delete item

A toolbar a jobb oldali panel tetején lesz, közvetlenül az
OrderItemTable felett.

Viselkedés:

-   Add → új üres sor + automatikus scroll
-   Delete → kijelölt sor törlése (ha van)
-   Auto‑empty row → ha az utolsó sor nem üres, automatikusan létrejön
    egy új üres sor

------------------------------------------------------------------------

3) Domain döntések

Az OrderItem:

-   rendelkezik saját ID‑val (QUuid)
-   a repository kezeli a CRUD műveleteket
-   a Presenter a domain API‑t hívja
-   a UI csak a táblát kezeli

Ezért:

-   Add → Presenter.createItem(orderId)
-   Delete → Presenter.deleteItem(itemId)
-   Edit → már működik (Presenter.saveOrder() kezeli)

------------------------------------------------------------------------

4) OrderItemTable bővítése

Új metódusok:

-   addEmptyRow()
-   deleteSelectedRow()
-   ensureEmptyRowAtBottom()
-   keyPressEvent() override (Enter → új sor)

------------------------------------------------------------------------

5) OrderWorkbenchPresenter bővítése

Új metódusok:

-   addItem()
-   deleteItem(const QUuid& itemId)

Ezek hívják az OrderManager megfelelő metódusait.

------------------------------------------------------------------------

6) OrderManager bővítése

Új metódusok:

-   createItem(orderId)
-   deleteItem(itemId)

Mindkettő a repository‑t hívja.

------------------------------------------------------------------------

7) OrderWorkbench UI bővítése

A jobb oldali panel tetejére új toolbar:

-   Add item
-   Delete item

A gombok a Presenter metódusait hívják.

------------------------------------------------------------------------

8) Integrációs sorrend

1.  OrderItemTable – UI logika
2.  Presenter – domain hívások
3.  Manager – repository hívások
4.  Workbench – toolbar + connect
5.  Teszt:
    -   új order → add item → edit → save
    -   load order → delete item → save
    -   auto‑empty row működik

------------------------------------------------------------------------
