✅ SKIP‑NODE PATCH – LÉPÉSRŐL LÉPÉSRE TERV

A skip‑node modell lényege:

-   Az Opt node nem ad vissza értéket, ha a feltétel hamis.
-   A szülő operátorok (pl. +) kihagyják a skip‑et.
-   A DSL szemantikája ettől még tisztább lesz.

A patch 5 pontból áll.

------------------------------------------------------------------------

1️⃣ LÉPÉS – Value típus bővítése (Skip hozzáadása)

Fájl: expression/value.h

Módosítás:

1.  Add hozzá az új típust:

    enum class Type { Number, String, Bool, Null, Skip };

2.  Adj hozzá egy gyári függvényt:

    static Value skipValue() {
        Value v;
        v.type = Type::Skip;
        return v;
    }

3.  A toString()‑ben kezeld:

    case Type::Skip: return "<skip>";

4.  A toBool()‑ban:

    case Type::Skip:
        if (ok) *ok = false;
        return false;

------------------------------------------------------------------------

2️⃣ LÉPÉS – Opt node módosítása SKIP visszaadásra

Fájl: expression/formula_engine.cpp

Módosítás:

A jelenlegi Opt ág:

    else
        return Value();

→ cseréld erre:

    else
        return Value::skipValue();

Ez jelzi a szülőnek: ezt az értéket hagyd ki.

------------------------------------------------------------------------

3️⃣ LÉPÉS – Operátorok módosítása, hogy kihagyják a SKIP‑et

Fájl: expression/formula_engine.cpp
Függvény: Value FormulaEngine::evalNode(AstNode* n, ...)

Módosítás:

A case AstNode::Type::Operator: ágban, mielőtt meghívod:

    Value v = reg.call(n->value, evalChildren(n, traceOut));

→ módosítsd úgy, hogy a skip‑eket kiszűrd:

    QVector<Value> args = evalChildren(n, traceOut);

    // skip-ek kiszűrése
    QVector<Value> filtered;
    for (const Value& a : args) {
        if (a.type != Value::Type::Skip)
            filtered.append(a);
    }

    // ha nincs operandus → null
    if (filtered.isEmpty()) {
        Value v = Value::nullValue();
        addTrace(v);
        return v;
    }

    // ha egy operandus → azt add vissza
    if (filtered.size() == 1) {
        Value v = filtered[0];
        addTrace(v);
        return v;
    }

    // különben → normál operátorhívás
    Value v = reg.call(n->value, filtered);
    addTrace(v);
    return v;

Ez a skip‑node modell szíve.

------------------------------------------------------------------------

4️⃣ LÉPÉS – Function hívásoknál is szűrd a SKIP‑et

Fájl: expression/formula_engine.cpp
Függvény: case AstNode::Type::Function:

Ugyanaz a logika, mint az operátoroknál:

-   skip → kihagyás
-   0 operandus → null
-   1 operandus → azt add vissza
-   több operandus → normál function call

------------------------------------------------------------------------

5️⃣ LÉPÉS – AST builder NEM módosul

Fájl: expression/ast_builder.cpp

A skip‑node modell nem igényel AST módosítást, mert:

-   az Opt node továbbra is 2 gyereket tartalmaz,
-   csak az evalNode viselkedése változik.
