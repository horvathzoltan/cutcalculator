1. LÉPÉS — OrderWorkbench UI skeleton (következő konkrét fejlesztési feladat)

Ez a legfontosabb, mert:

-   a domain kész
-   a repositoryk kész
-   a registryk kész
-   a pipeline működik
-   a ZIP‑archiválás stabil
-   a rendszer használhatóvá válik

1.1. OrderWorkbench osztály létrehozása

-   workbench/view/order_workbench.h/.cpp
-   BOMWorkbench mintájára
-   fő komponensek:
    -   HeaderPanel
    -   ItemTable
    -   Toolbar (New / Save / Load / Delete)

1.2. HeaderPanel UI

Mezők: - customerName
- orderDate
- defaultColor
- defaultHandlerSide
- defaultExternalPrefix
- note
- status
- deadline

Feladatok: - kétirányú binding a modellel
- validáció (customerName kötelező)

1.3. OrderItemTable UI

Oszlopok: - productId (combobox)
- width_mm
- height_mm
- handlerSide
- colorName
- externalId
- order_qty
- modeName

Feladatok: - sor hozzáadása / törlése
- cella‑szerkesztés
- validáció (productId, qty)

1.4. Save / Load gombok

-   Save → OrderHeaderRegistry.update() + OrderItemRegistry.update()
-   Load → registry.findById(headerId) + findByOrderId(headerId)
-   UI frissítése

1.5. Filter mezők (egyszerű Query)

-   customerName filter
-   status filter
-   dátum intervallum filter

Megvalósítás: - registry.findAll(&{…})
- eredmény → UI listába
