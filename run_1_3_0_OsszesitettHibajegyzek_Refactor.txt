### Cél

Legyen egy **általános, bővíthető UIStateCollector**, ami:

- **automatikusan** végigmegy egy `QWidget` fán,
- **típus alapján** felismeri a „state‑kritikus” widgeteket,
- **kiveszi** belőlük a releváns UI‑állapotot (splitter, header, tab, scroll, stb.),
- **név alapján** elmenti,
- induláskor **név alapján visszatölti**,
- a Workbench csak annyit mond:
  **„itt a root widgetem, mentsd/restore‑old az UI‑t”**.

---

## 1. Alap API

```cpp
class UIStateCollector
{
public:
    explicit UIStateCollector(const QString& groupName);

    void collect(QWidget* root);   // mentés
    void restore(QWidget* root);   // visszaállítás

private:
    QString _groupName; // pl. "bom_workbench"
};
```

- **`groupName`**: logikai név (pl. workbench azonosító) → ini/json szekció prefix.
- A konkrét storage lehet `QSettings`, saját ini, json, bármi.

---

## 2. Widget bejárás

Ugyanaz a minta, mint a WindowStabilityMonitorban, csak más szűrővel:

```cpp
QList<QWidget*> UIStateCollector::collectWidgets(QWidget* root) const
{
    QList<QWidget*> list;
    if (!root)
        return list;

    list << root;

    const auto children = root->findChildren<QWidget*>(QString(), Qt::FindDirectChildrenOnly);
    for (QWidget* c : children)
        list << collectWidgets(c);

    return list;
}
```

Itt nem kell annyira agresszíven szűrni, mint a layout‑kritikusnál, mert a típus‑alapú extractornál úgyis kiszűrjük, ami nem érdekes.

## 3. Típus‑alapú extractor/restorer registry

### Interface

```cpp
using ExtractFn  = std::function<void(QWidget*, QSettings&, const QString& keyPrefix)>;
using RestoreFn  = std::function<void(QWidget*, QSettings&, const QString& keyPrefix)>;

struct Handler {
    ExtractFn extract;
    RestoreFn restore;
};

class UIStateCollector
{
    ...
    QHash<QByteArray, Handler> _handlers; // metaObject()->className() → handler
};
```

### Regisztráció (konstruktorban vagy statikusan)

```cpp
UIStateCollector::UIStateCollector(const QString& groupName)
    : _groupName(groupName)
{
    registerHandler<QSplitter>(
        &UIStateCollector::extractSplitter,
        &UIStateCollector::restoreSplitter);

    registerHandler<QHeaderView>(
        &UIStateCollector::extractHeader,
        &UIStateCollector::restoreHeader);

    registerHandler<QTabWidget>(
        &UIStateCollector::extractTabWidget,
        &UIStateCollector::restoreTabWidget);

    registerHandler<QAbstractScrollArea>(
        &UIStateCollector::extractScrollArea,
        &UIStateCollector::restoreScrollArea);

    // később bővíthető: QTableView, QTreeView, stb.
}
```

Helper:

```cpp
template<typename T>
void UIStateCollector::registerHandler(ExtractFn e, RestoreFn r)
{
    _handlers.insert(T::staticMetaObject.className(), Handler{e, r});
}
```

## 4. Kulcsgenerálás (név alapú)

Minden widgethez kell egy **stabil azonosító**:

```cpp
QString UIStateCollector::keyFor(QWidget* w) const
{
    QString name = w->objectName();
    if (name.isEmpty())
        name = QString::fromLatin1(w->metaObject()->className());

    // pl: "bom_workbench/QSplitter/splitter_main"
    return _groupName + "/" + QString::fromLatin1(w->metaObject()->className()) + "/" + name;
}
```

Ez lesz a prefix, pl.:

- `bom_workbench/QSplitter/splitter_main/sizes`
- `bom_workbench/QHeaderView/table_products/columns`
- `bom_workbench/QTabWidget/main_tabs/currentIndex`

---

## 5. collect() és restore() logika

```cpp
void UIStateCollector::collect(QWidget* root)
{
    if (!root) return;

    QSettings s; // vagy saját wrapper
    const auto widgets = collectWidgets(root);

    for (QWidget* w : widgets) {
        const auto className = w->metaObject()->className();
        if (!_handlers.contains(className))
            continue;

        const auto keyPrefix = keyFor(w);
        _handlers[className].extract(w, s, keyPrefix);
    }
}

void UIStateCollector::restore(QWidget* root)
{
    if (!root) return;

    QSettings s;
    const auto widgets = collectWidgets(root);

    for (QWidget* w : widgets) {
        const auto className = w->metaObject()->className();
        if (!_handlers.contains(className))
            continue;

        const auto keyPrefix = keyFor(w);
        _handlers[className].restore(w, s, keyPrefix);
    }
}
```

## 6. Konkrét handlerek

### 6.1 QSplitter

```cpp
void UIStateCollector::extractSplitter(QWidget* w, QSettings& s, const QString& key)
{
    auto* splitter = qobject_cast<QSplitter*>(w);
    if (!splitter) return;

    const auto sizes = splitter->sizes();
    if (sizes.isEmpty()) return;

    int sum = 0;
    for (int v : sizes) sum += v;
    if (sum <= 0) return;

    QVariantList percents;
    for (int v : sizes)
        percents << double(v) / double(sum);

    s.setValue(key + "/sizes", percents);
}

void UIStateCollector::restoreSplitter(QWidget* w, QSettings& s, const QString& key)
{
    auto* splitter = qobject_cast<QSplitter*>(w);
    if (!splitter) return;

    const auto percents = s.value(key + "/sizes").toList();
    if (percents.isEmpty()) return;

    const int total = splitter->orientation() == Qt::Horizontal
                      ? splitter->width()
                      : splitter->height();

    QList<int> sizes;
    for (const auto& v : percents)
        sizes << int(v.toDouble() * total);

    splitter->setSizes(sizes);
}
```

(gyakorlatilag a mostani splitter‑mentésed általánosítva)

### 6.2 QHeaderView

```cpp
void UIStateCollector::extractHeader(QWidget* w, QSettings& s, const QString& key)
{
    auto* header = qobject_cast<QHeaderView*>(w);
    if (!header) return;

    const int count = header->count();
    if (count <= 0) return;

    QVariantList widths;
    for (int i = 0; i < count; ++i)
        widths << header->sectionSize(i);

    s.setValue(key + "/widths", widths);
    s.setValue(key + "/sortSection", header->sortIndicatorSection());
    s.setValue(key + "/sortOrder", int(header->sortIndicatorOrder()));
}

void UIStateCollector::restoreHeader(QWidget* w, QSettings& s, const QString& key)
{
    auto* header = qobject_cast<QHeaderView*>(w);
    if (!header) return;

    const auto widths = s.value(key + "/widths").toList();
    if (!widths.isEmpty()) {
        const int count = std::min(header->count(), widths.size());
        for (int i = 0; i < count; ++i)
            header->resizeSection(i, widths[i].toInt());
    }

    const int sortSection = s.value(key + "/sortSection", -1).toInt();
    const auto sortOrder = Qt::SortOrder(s.value(key + "/sortOrder", int(Qt::AscendingOrder)).toInt());
    if (sortSection >= 0 && sortSection < header->count())
        header->setSortIndicator(sortSection, sortOrder);
}
```

### 6.3 QTabWidget

```cpp
void UIStateCollector::extractTabWidget(QWidget* w, QSettings& s, const QString& key)
{
    auto* tabs = qobject_cast<QTabWidget*>(w);
    if (!tabs) return;

    s.setValue(key + "/currentIndex", tabs->currentIndex());
}

void UIStateCollector::restoreTabWidget(QWidget* w, QSettings& s, const QString& key)
{
    auto* tabs = qobject_cast<QTabWidget*>(w);
    if (!tabs) return;

    int idx = s.value(key + "/currentIndex", -1).toInt();
    if (idx >= 0 && idx < tabs->count())
        tabs->setCurrentIndex(idx);
}
```

---

### 6.4 QAbstractScrollArea (scroll pozíció)

```cpp
void UIStateCollector::extractScrollArea(QWidget* w, QSettings& s, const QString& key)
{
    auto* area = qobject_cast<QAbstractScrollArea*>(w);
    if (!area) return;

    auto* h = area->horizontalScrollBar();
    auto* v = area->verticalScrollBar();
    if (h) s.setValue(key + "/hScroll", h->value());
    if (v) s.setValue(key + "/vScroll", v->value());
}

void UIStateCollector::restoreScrollArea(QWidget* w, QSettings& s, const QString& key)
{
    auto* area = qobject_cast<QAbstractScrollArea*>(w);
    if (!area) return;

    auto* h = area->horizontalScrollBar();
    auto* v = area->verticalScrollBar();
    if (h) h->setValue(s.value(key + "/hScroll", h->value()).toInt());
    if (v) v->setValue(s.value(key + "/vScroll", v->value()).toInt());
}
```

## 7. Integráció a Workbench‑be

A Workbench kódja ideális esetben ennyi:

```cpp
void BOMWorkbench::restoreUiState()
{
    UIStateCollector c("bom_workbench");
    c.restore(this);
}

void BOMWorkbench::saveUiState()
{
    UIStateCollector c("bom_workbench");
    c.collect(this);
}
```

És a WindowStabilityMonitor:

- csak annyit tesz, hogy a `windowStable()` jelre meghívod a `restoreUiState()`‑et,
- kilépéskor / closeEvent‑ben pedig `saveUiState()`.

---

## 8. Mit nyersz ezzel?

- **A UI adja az UI‑logikát** → a collector ismeri a widgeteket, nem a Workbench.
- **A Workbench tisztán domain‑logika** marad.
- **Bővíthető**: ha holnap akarsz `QTreeView` expanded state‑et menteni, csak egy új handler kell.
- **Determinista**: a WindowStabilityMonitor gondoskodik róla, hogy restore csak stabil layout után fusson.
- **Egységes**: minden Workbench, minden tool window ugyanazt a mechanizmust használja.
- **Ipari minta**: pont így csinálja Qt Creator, VSCode, IntelliJ, stb.

Ha szeretnéd, a következő lépés lehet egy konkrét `ui_state_collector.h/.cpp` teljes, kompakt implementáció, amit be tudsz dobni a projektbe és elkezdeni használni.
