⭐ P8 – A FormulaEngine teljes újraírása

A kompromisszummentes, pengeéles verzió

1) A FormulaEngine::eval visszatérési típusa: bool

Pontosan, ahogy mondtad.

A FormulaEngine:

-   AST‑et futtat
-   változókat ír a VariableRepository‑ba
-   nem ad vissza értéket
-   nem csomagol semmit
-   nem találgat
-   csak azt mondja: sikerült / nem sikerült

    bool FormulaEngine::eval(const QString& code);

A hívó kód:

    FormulaEngine::eval("a = 10");
    int a = vars.get("a").toInt();

Ez a tiszta modell.

⭐ 2) A FormulaEngine NEM tart fenn saját értéket

Nincs EvaluatedFormula.
Nincs length_mm.
Nincs pieces.
Nincs text.

A FormulaEngine nem tud semmit arról, hogy a hívó kód mire használja az
értékeket.

A FormulaEngine csak:

-   értelmez,
-   számol,
-   repo‑ba ír.

Ez a helyes rétegzés.

⭐ 3) A nyelv runtime‑típusa: Value

Nem QVariant.
Nem EvaluatedFormula.
Nem QString/int/bool keverék.

Egyetlen, tiszta, típusos érték:

    struct Value {
        enum class Type { Number, String, Bool, Null };

        Type type = Type::Null;
        double number = 0.0;
        QString text;
        bool boolean = false;

        static Value number(double n) { Value v; v.type=Type::Number; v.number=n; return v; }
        static Value string(const QString& s) { Value v; v.type=Type::String; v.text=s; return v; }
        static Value boolean(bool b) { Value v; v.type=Type::Bool; v.boolean=b; return v; }
        static Value null() { return {}; }
    };

Ez:

-   gyors,
-   egyszerű,
-   típusbiztos,
-   nincs implicit konverzió,
-   nincs heurisztika,
-   nincs QVariant‑mágia.

Ez a nyelv runtime‑ja.

⭐ 5) A FormulaEngine AST‑evalja közvetlenül Value‑t ad vissza

Nincs AstToExpression.
Nincs Expression::Parse.
Nincs Expression::Calculate.
Nincs mini DSL.

A teljes eval így néz ki:

    Value FormulaEngine::evalNode(AstNode* n)
    {
        switch (n->type) {

            case AstNode::Type::Number:
                return Value::number(n->value.toDouble());

            case AstNode::Type::StringLiteral:
                return Value::string(n->value);

            case AstNode::Type::Variable:
                return vars.get(n->value);

            case AstNode::Type::Operator:
                return callFunction(n->value, evalChildren(n));

            case AstNode::Type::Function:
                return callFunction(n->value, evalChildren(n));

            case AstNode::Type::Assignment:
                vars.set(n->value, evalNode(n->children[0]));
                return Value::null();

            case AstNode::Type::Return:
                return evalReturn(n);

            case AstNode::Type::Choose:
                return evalChoose(n);

            case AstNode::Type::Opt:
                return evalOpt(n);
        }
    }

Ez a tiszta, direkt AST‑eval.

⭐ 6) Függvénycentrikus világ

Ez a nyelv lényege.

Minden művelet → függvény.

-   + → add
-   - → sub
-   * → mul
-   / → div
-   > → gt
-   < → lt
-   >= → ge
-   <= → le
-   == → eq
-   choose → choose
-   opt → opt
-   qty_fixed → qty_fixed
-   qty_perOrder → qty_perOrder
-   qty_perArea → qty_perArea
-   a = expr → set(a, expr)
-   return a=..., b=... → return struct

A FunctionRegistry:

    using NativeFn = std::function<Value(const QVector<Value>&)>;

    QMap<QString, NativeFn> registry;

    registry["add"] = [](auto args){ return Value::number(args[0].number + args[1].number); };
    registry["mul"] = [](auto args){ return Value::number(args[0].number * args[1].number); };
    registry["qty_fixed"] = [](auto args){ return Value::number(args[0].number * args[1].number); };
    ...

Ez a Lisp‑szerű, egységes, tiszta modell.

⭐ 7) A FormulaEngine::eval() végleges formája

    bool FormulaEngine::eval(const QString& code)
    {
        auto tokens = Tokenizer::tokenize(code);
        auto rpn    = Parser::toRpn(tokens);
        AstNode* ast = AstBuilder::fromRpn(rpn);

        if (!ast)
            return false;

        try {
            evalNode(ast);
            return true;
        } catch (...) {
            return false;
        }
    }

Ennyi.

⭐ 8) Mi marad a hívó C++ kódra?

A hívó:

-   meghívja az eval‑t,
-   majd a repo‑ból olvas.

Például:

    FormulaEngine::eval("length = w*h/1000");
    double len = vars.get("length").number;

Vagy:

    FormulaEngine::eval("return length = w*h/1000, pieces = qty_fixed(qty,3)");
    double len = vars.get("length").number;
    double pcs = vars.get("pieces").number;

Ez a tiszta, kompromisszummentes modell.
