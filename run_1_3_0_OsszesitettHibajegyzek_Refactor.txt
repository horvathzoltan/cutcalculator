🔥 8. Save workflow implementálása

Lépések:

1.  header = headerPanel.toHeader()
2.  items = itemTable.toItems()
3.  OrderHeaderRegistry::instance().update(header)
4.  OrderItemRegistry::instance().update(item) minden tételre
5.  UI refresh
6.  success → zEventINFO(“Order saved”)

------------------------------------------------------------------------

🔥 9. Load workflow implementálása

1.  header = OrderHeaderRegistry::findById(id)
2.  items = OrderItemRegistry::findByOrderId(id)
3.  headerPanel.setHeader(header)
4.  itemTable.setItems(items)
5.  UI refresh
