-   customerName kötelező

------------------------------------------------------------------------

🔥 C) Save / Load workflow – részletes terv

1) Save

-   header = headerPanel.toHeader()
-   items = itemTable.toItems()
-   registry.update(header)
-   registry.update(items)
-   success → UI refresh

2) Load

-   header = OrderHeaderRegistry::findById(id)
-   items = OrderItemRegistry::findByOrderId(id)
-   headerPanel.setHeader(header)
-   itemTable.setItems(items)

------------------------------------------------------------------------

🔥 D) Filter mezők – részletes terv

1) UI mezők

-   customerName filter
-   status filter
-   date interval

2) Query

    registry.findAll([&](const OrderHeader& h){
        return h.customerName.contains(text)
            && h.status == selectedStatus
            && h.orderDate in interval;
    });
