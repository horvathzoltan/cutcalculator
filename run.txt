
📝 Mai nap összefoglalója (tömör, fejlesztőbarát, teljes)

A mai nap a CutCalculator egyik legfontosabb stabilizációs és
UX‑minőségi napja volt. Három nagy területet zártunk le:
(1) fájlkezelési réteg auditálása,
(2) OverlayIconWidget teljes architektúrája,
(3) NeedCalculation adatvesztési hiba feltárása.
Mindhárom terület közvetlenül növeli a rendszer megbízhatóságát,
diagnosztikáját és fejlesztői élményét.

🔧 1. Fájlkezelési réteg stabilizálása

Bevezettünk egy egységes, kontextusos fájlhiba‑loggert, amely minden
.open() hívást auditál:

-   READ/WRITE mód külön logolva
-   OpenMode explicit megjelenítve
-   abszolút path + létezés + hibakód + hibaszöveg
-   minden repository és CSV művelet mostantól átlátható

Ez a lépés megszüntette a korábbi „néma hibákat”, és lehetővé tette a
NeedCalculation adatvesztési hiba teljes feltárását.

🎨 2. OverlayIconWidget — teljes rendszerkomponenssé vált

A widget ma elérte a végleges architektúrát:

-   kétlépcsős cache (RAM + file)
-   determinisztikus kulcsgenerálás
-   baseline‑helyes overlay pozicionálás
-   crop → tint → scale → cache pipeline stabil
-   paintEvent optimalizálva, toolbar redraw nem okoz terhelést
-   verbose logok auditálhatók, nem zajosak

Ez a komponens mostantól a projekt egyik legfontosabb UX‑eleme, és
alapot ad a „létezés overlay” rendszer-szintű bevezetéséhez.

🐿️ 3. NeedCalculation adatvesztési hiba feltárása

A „mókus” eltűnésének oka 100%-osan beazonosítva:

-   a NeedCalculation CSV‑k hiánya miatt a SAVE hibázott
-   a repository automatikusan újratöltött
-   a reload törölte a memóriában lévő adatot
-   ezért tűnt el a mókus a UI‑ból

A hiba gyökere: SAVE→RELOAD minta.
Döntés: mentési hiba után nem lesz többé reload.

📦 4. CSV‑importer hibakezelés egységesítése

-   READ hibák kontextusos loggal
-   szeparátor‑detektálás fallback auditálva
-   importer viselkedése kiszámíthatóbbá vált

🧭 5. Snapshot‑restore pipeline validálása

A logok alapján a snapshot rendszer:

-   DPI‑profil alapján működik
-   splitter/header állapotok helyesen állnak vissza
-   deferred restore működik

💡 6. Új ötletek és architekturális irányok

-   FileOpLogger / FileAccessContext mint egységes réteg
-   SystemLog + EventLog szétválasztása
-   CSV warning ikonváltás
-   OverlayIconWidget globális integrációs szabály
-   ModeNameDialog további UX finomítás
