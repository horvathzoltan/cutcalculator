📊 Idővonalas roadmap

✅ Elkészült - Material pipeline (Stage2.5 validátorral) - RalImporter
modul (NormalizedRal, auditbarát duplikátumkezelés) - Product pipeline
(fa megjelenítés, export/import formátum javítva) - Logger subsystem -
Startup subsystem - Settings subsystem - FileNameHelper - Test
framework - NamedColor / Color registry refaktor → repo pattern,
RegistryManager audit összefoglaló, Pantone integráció előkészítve -
RegistryBase + RegistryManager → automatikus audit összefoglaló

🚧 Folyamatban - OrderManager - CustomerMaster - CutCalculator -
NeedsPresenter + NeedsView - UI réteg (Order entry dialog, Needs
preview) - Audit funkció - NeedRule / NeedCalculation kapcsolótábla – új
koncepció kidolgozás alatt - Formula értelmezés – cparse integráció
előkészítése

⚠️ Függőség / Részben kész - CsvReader utility

➕ Új ötlet / Jövőbeli irány - Real‑time preview - DataStateReporter -
ColorRepository pattern (RAL + Pantone + Custom paletták integrálása,
auditbarát törzsadat kezelés) - cparse integráció – auditbarát formula
parser - Kapcsolótábla modell – NeedRule + NeedCalculation
szétválasztás, string alapú számítási módok
