🔵 A) FŐ KOMPONENS SZINT – frissítve

(Top‑level modulok, mindegyikhez 1 mondatos projektbeli szerep)

🧩 Common / Core Infrastructure

-   Utils – Alapvető segédletek: fájlkezelés, geometry helper, event
    util, optional utils, font utils.
-   Layout – Alapértelmezett UI‑layoutok tárolása és visszaállítása
    (percent‑based, monitor‑profil aware).
-   Snapshot – Munkaterület és UI‑állapotok mentése/visszatöltése
    (WorkbenchSnapshot + GeometryHelper).
-   Settings – INI‑alapú beállításkezelés, snapshot‑ és
    layout‑integrációval.
-   System – Életciklus, verbose logolás, window‑figyelés, buildinfo,
    sysinfo.
-   Registry Infrastructure – A domain‑modellek alapja: registry_core,
    mixinek, traits, lookup, subscription.

🧩 Registry‑Driven Domain Model

-   Registry Base/Core – Absztrakció és engine minden domain‑entitás
    számára (RegistryEngineBase + RegistryCore).
-   Registry Manager – Betöltés, validálás, lookup,
    repository‑integráció, audit‑barát működés.
-   Registry Traits / Mixins – Típus‑specifikus metaadatok,
    CRUD/connection/barcode mixinek.

🧩 Materials

-   Material Model – Anyagok, keresztmetszetek, vágási/festési módok,
    cutting/painting mode.
-   Material Registry – Anyagok betöltése, validálása, barcode‑index
    integráció.
-   Material Repository – Anyagadatok tárolása, háromfázisú CSV import.
-   Material Views – Anyagtáblák, színjelvények, UI‑kezelők
    (MaterialTableWidget + Manager + ColorBadge).

🧩 Products

-   Product Model – Termékek, termékfa, hierarchikus struktúra
    (ProductMaster).
-   Product Registry – Termékadatok betöltése, lookup, children/roots
    lekérdezés.
-   Product Repository – Termékadatok tárolása, háromfázisú import.
-   Product Views – Termékfa UI (ProductTreeView + ProductTreePanel +
    ProductTreeManager).
-   Product Presenter – ProductTreePresenter: toolbar, overlay‑ikon,
    registry‑vezérelt státusz.

🧩 Needs / Need Rules

-   Need Rule Model – Anyagszükséglet‑szabályok (kapcsolat product ↔
    material).
-   Need Rule Registry – Szabályok betöltése, validálása, audit‑barát
    pipeline.
-   Need Rule Repository – Szabályadatok tárolása, CSV import.
-   Material Requirements Manager – Anyagszükséglet számítási pipeline
    (NeedRule + Material).
-   Needs Presenters – MaterialRequirementsPresenter: product selection
    → szükséglet nézet frissítés.
-   Needs Views – Picker dialogok, requirements nézetek
    (MaterialRequirementsView, MaterialPickerDialog).

🧩 Calculation / CalcModes

-   Calculation Mode Model – Számítási módok definíciói
    (NeedCalculation).
-   Calculation Detail Model – Részletes számítási lépések
    (NeedCalculationDetail).
-   Calculation Registries – Módok és részletek regisztere
    (NeedCalculationRegistry, NeedCalculationDetailRegistry).
-   Calculation Repositories – Adatforrások a számítási módokhoz és
    részletekhez.
-   Need Calculator Service – A tényleges számítási motor
    (NeedCalculator).
-   Calculation Managers – Módok és részletek kezelése
    (CalculationModesManager, CalculationModeDetailManager).
-   Calculation Presenters – CalculationModesPresenter,
    CalculationModeDetailPresenter: overlay, selection, refresh.
-   Calculation Views – Módválasztó és részletnézet UI
    (CalculationModesView, CalculationModeDetailView).

🧩 Barcodes

-   Barcode Model – Vonalkód entitások (BarcodeRecord).
-   Barcode Registry – Vonalkódok betöltése, lookup, ütközés‑ellenőrzés.
-   Barcode Repository – Vonalkódadatok tárolása, CSV import.
-   Barcode Collision Helper – Ütközésvizsgálat, audit‑barát riport.
-   Barcode Validator – Validálási logika, egyediség‑ellenőrzés.

🧩 CSV Import / FileContext

-   FileContext Pipeline – Import kontextus, hibagyűjtés,
    path‑információk.
-   CSV Helper – CSV‑feldolgozás segédletei.
-   CSV Importer – Teljes importfolyamat (háromfázisú import koncepció).
-   RowError – Sor‑szintű hibamodellek, auditálható hibalista.

🧩 Logger

-   Logger Core – Alap logolási infrastruktúra (Logger, LogManager).
-   Event Logger – Eseményalapú logolás, user‑szintű események.
-   Error Bucketizer – Hibák csoportosítása, CSV import és registry
    audit támogatás.
-   Logger GUI / Adapter – Logok UI‑ba kötése (LogViewAdapter,
    logger_gui).

🧩 Startup / Lifecycle

-   Startup Manager – Indítási pipeline, fázisok, registry‑init, CSV
    import.
-   Startup Status – Státuszmodellek, user‑felé kommunikálható
    állapotok.
-   Startup Status Manager – Státuszok kezelése, UI‑szinkron.
-   Lifecycle Manager – Alkalmazás életciklusának kezelése (startup →
    shutdown).

🧩 UI / Widgets

-   Overlay Icon Widget – Emoji/ikon overlay rendszer, domain‑vezérelt
    státuszjelzés.
-   MainWindow – Főablak, docking, menük, BOMWorkbench integráció,
    snapshot‑aware.

🧩 Workbench

-   BOM Workbench – Központi munkaterület: ProductTree + Needs +
    CalcModes + Details, snapshot‑képes, splitter‑vezérelt layout.

🧩 Test Framework

-   Test Manager – Tesztfuttató infrastruktúra.
-   Logger Tests / Smoke Tests – Logger‑tesztek, registry smoke‑tesztek
    (MaterialRegistry, stb.).

    lambda‑event minták.

    monitor‑profil aware.

    (splitter, header, layout).
-   settings_manager – INI‑alapú beállításkezelés, path‑kezelés.

    regisztrálása típusonként.
-   lifecycle_manager – Alkalmazás életciklusának kezelése (startup →
    shutdown).
-   window_observer – Ablak‑figyelés, fókuszváltás, láthatóság.
-   signal_helper – Qt signal/slot segédletek.
-   sysinfo_helper – Rendszerinformációk lekérdezése.
-   buildnumber – Build‑szám generálás / beégetés.
-   registry_base / registry_core / registry_manager / registry_traits /
    mixins – Registry‑alap interfész, engine, manager, típus‑specifikus
    viselkedések.
-   color_badge – Színes jelvény widget (anyagokhoz).
-   barcode_collision_helper – Vonalkód‑ütközés vizsgálat.
-   barcode_validator – Vonalkód‑validálás.
-   filecontext / filecontext_collector / csvhelper / csvimporter /
    rowerror – CSV import pipeline, hibamodellek, kontextus.
-   event_logger / error_bucketizer / log_view_adapter – Eseménylogolás,
    hibacsoportosítás, UI‑adapter.
-   startup_manager / startup_status / startup_status_manager – Indítási
    pipeline, státuszmodell, UI‑szinkron.
-   overlay_icon_widget – Emoji‑/ikon‑overlay widget, domain‑vezérelt
    státusz helperrel.
-   test_manager / eventlogger_tests / material_registry_smoke_test –
    Tesztfuttató keretrendszer és kulcs tesztek.
