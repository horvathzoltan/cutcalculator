🔵 A) FŐ KOMPONENS SZINT

(Top‑level modulok, mindegyikhez 1 mondatos projektbeli szerep)

🧩 Common / Core Infrastructure

-   Utils – Alapvető segédletek: fájlkezelés, geometry helper, event
    util, optional utils.
-   Layout – Alapértelmezett UI‑layoutok tárolása és visszaállítása.
-   Snapshot – Munkaterület és UI‑állapotok mentése/visszatöltése.
-   Settings – INI‑alapú beállításkezelés.
-   System – Életciklus, verbose logolás, window‑figyelés, buildinfo.
-   Registry Infrastructure – A domain‑modellek alapja: registry,
    traits, lookup.

🧩 Registry‑Driven Domain Model

-   Registry Base – Absztrakció minden domain‑entitás számára.
-   Registry Manager – Betöltés, validálás, lookup,
    repository‑integráció.
-   Registry Traits – Típus‑specifikus metaadatok.

🧩 Materials

-   Material Model – Anyagok, keresztmetszetek, vágási/festési módok.
-   Material Registry – Anyagok betöltése és validálása.
-   Material Repository – Anyagadatok tárolása, CSV/DB források.
-   Material Views – Anyagtáblák, színjelvények, UI‑kezelők.

🧩 Products

-   Product Model – Termékek, termékfa, hierarchikus struktúra.
-   Product Registry – Termékadatok betöltése és lookup.
-   Product Repository – Termékadatok tárolása.
-   Product Views – Termékfa UI, kezelők, nézetlogika.

🧩 Needs / Need Rules

-   Need Rule Model – Anyagszükséglet‑szabályok.
-   Need Rule Registry – Szabályok betöltése, validálása.
-   Need Rule Repository – Szabályadatok tárolása.
-   Material Requirements Manager – Anyagszükséglet számítási pipeline.
-   Needs Views – Picker dialogok, requirements nézetek.

🧩 Calculation / CalcModes

-   Calculation Mode Model – Számítási módok definíciói.
-   Calculation Detail Model – Részletes számítási lépések.
-   Calculation Registries – Módok és részletek regisztere.
-   Calculation Repositories – Adatforrások a számítási módokhoz.
-   Need Calculator Service – A tényleges számítási motor.
-   Calculation Managers – Módok és részletek kezelése.
-   Calculation Views – Módválasztó és részletnézet UI.

🧩 Barcodes

-   Barcode Model – Vonalkód entitások.
-   Barcode Registry – Vonalkódok betöltése és lookup.
-   Barcode Repository – Vonalkódadatok tárolása.
-   Barcode Collision Helper – Ütközésvizsgálat.
-   Barcode Validator – Validálási logika.

🧩 CSV Import / FileContext

-   FileContext Pipeline – Import kontextus, hibagyűjtés.
-   CSV Helper – CSV‑feldolgozás segédletei.
-   CSV Importer – Teljes importfolyamat.
-   RowError – Sor‑szintű hibamodellek.

🧩 Logger

-   Logger Core – Alap logolási infrastruktúra.
-   Log Manager – Logfolyamok kezelése.
-   Event Logger – Eseményalapú logolás.
-   Error Bucketizer – Hibák csoportosítása.
-   Log View Adapter – Logok UI‑ba kötése.

🧩 Startup / Lifecycle

-   Startup Manager – Indítási pipeline, fázisok.
-   Startup Status – Státuszmodellek.
-   Lifecycle Manager – Alkalmazás életciklusának kezelése.

🧩 UI / Widgets

-   Overlay Icon Widget – Emoji/ikon overlay rendszer.
-   MainWindow – Főablak, docking, menük, integráció.

🧩 Workbench

-   BOM Workbench – Központi munkaterület, snapshot‑képes.

🧩 Test Framework

-   Test Manager – Tesztfuttató infrastruktúra.
-   Logger Tests – Logrendszer tesztjei.
