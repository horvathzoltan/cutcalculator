✅ Egyszerű, gyors feature‑spec (fejlesztői task listához)
Ez a prompt akkor kell, amikor egy új funkciót akarsz megtervezni.
Gyors, tömör, fejlesztőbarát, Copilot‑optimalizált.:

---------------------------------------------------------------------------------------------
Adj egy tömör, fejlesztőbarát specifikációt a következő funkcióhoz:

- Követelményspecifikáció
- Funkcionális specifikáció
- Implementációs terv
- Használj emojikat
- Markdown formátum

A specifikáció legyen:
- rövid és lényegre törő
- fejlesztői task listára optimalizált
- Copilot-barát (világos, egyértelmű, moduláris)
- ne legyen túlbeszélt
- csak a megvalósítandó funkcióra fókuszáljon

A cél: gyors, végrehajtható fejlesztési terv.
---------------------------------------------------------------------------------------------

✅ Ipari szintű architektúra dokumentum
Ez a prompt akkor kell, amikor egy alrendszert, architektúrát vagy komplex modult akarsz dokumentálni.
Ez lesz a projekt hivatalos dokumentációja.

---------------------------------------------------------------------------------------------
Készíts egy részletes, ipari szintű architektúra dokumentumot a következő funkcióhoz.

A dokumentum tartalmazza:

- Probléma leírása és kontextus
- Követelményspecifikáció
- Architektúra áttekintés
- Modulok és felelősségi körök
- Adatmodellek
- Folyamatok (startup, shutdown, restore, save)
- Guardok, edge case-ek, deferred logika
- Audit logika
- Bővíthetőség és jövőbeli irányok
- Gyakorlati példák
- Markdown formátum
- Fejlesztőbarát, olvasmányos stílus
- Emojik, ahol segítik a megértést

A cél:
- új fejlesztők gyors onboardingja
- Copilot számára teljes kontextus biztosítása
- ipari szintű, hosszú távon fenntartható dokumentáció
---------------------------------------------------------------------------------------------


✅ 1) A kettes dokumentum → állandó architektúra
Ezt időnként frissítjük, ha:
    - új modul kerül be
    - új snapshot szekció jelenik meg
    - új restore/mentés logika épül be

De ritkán változik.

✅ 2) Minden új funkció → egyes dokumentum
A promptból generáljuk:

    - funkcionális specifikáció
    - implementációs terv
    - emojikkal
    - Markdownban

Ez lesz a fejlesztői task listád.

✅ 3) A fejlesztés → a kettő alapján történik
A kettes adja a kontextust,
Az egyes adja a konkrét feladatot,
nincs szükség semmi másra.

Zoltán, ez a kis „Hogyan működik” blokk nagyon jó irány, de ha
audit‑szemmel nézzük, akkor néhány pontot érdemes finomítani, hogy:

-   egyértelmű legyen, mit csinál a script,
-   ne legyen félreérthető, mikor kell -d,
-   világos legyen, hogy a globok a ROOT alatt oldódnak fel,
-   és ne legyen olyan példa, ami félrevezető vagy hibás működéshez
    vezethet.

Az alábbiakban átnézem, majd adok egy auditált, tiszta, véglegesített
verziót.

------------------------------------------------------------------------

🔍 Audit – részletes értékelés

1) Teljes projekt dumpolása

    ./sourcetotxt.sh ~/source/repos/CutCalculator/ > masi2.txt

✔️ Ez jó.
A script felismeri, hogy az argumentum könyvtár → rekurzívan dumpol.

Megjegyzés:
Itt nem kell -d, mert a teljes pathot adod meg.

------------------------------------------------------------------------

2) Specifikus könyvtár dumpolása

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator products

✔️ Ez is jó.
A script a products könyvtárat a ROOT alatt keresi.

------------------------------------------------------------------------

3) Fájllista használata

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator files.txt

✔️ Ez is helyes.
A script felismeri, hogy files.txt létező fájl → fájllista mód.

Megjegyzés:
A fájllistában lévő globok is működnek, ha * van bennük.

------------------------------------------------------------------------

4) Mintás fájlok – run_5*

✨ Hogyan működik – sourcetotxt.sh

A script képes:

-   teljes könyvtárakat dumpolni,
-   konkrét fájlokat kiírni,
-   fájllistát feldolgozni,
-   glob mintákat (pl. run_5*, *repo*, *reg*) a ROOT alatt rekurzívan
    feloldani.

A a *repo* és *reg* minták a projekt teljes fáfa‑struktúrájában
működnek.

------------------------------------------------------------------------

📁 Könyvtár dumpolása

Teljes projekt:

    ./sourcetotxt.sh ~/source/repos/CutCalculator/ > masi2.txt

Specifikus könyvtár:

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator products

------------------------------------------------------------------------

📄 Fájlok listából

A files.txt tartalmazhat:

-   konkrét fájlokat
-   könyvtárakat
-   glob mintákat (*repo*, *reg*, run_5*)

Parancs:

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator files.txt

------------------------------------------------------------------------

🔍 Mintás fájlok (globok)

run_5* mintázat:

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator "run_5*" > masi2.txt

repository + registry mintázatok:

    ./sourcetotxt.sh -d ~/source/repos/CutCalculator "*repo*" "*reg*" > masi2.txt

A script ezeket rekurzívan oldja fel:

    $ROOT/**/$INPUT

Így minden repository és registry fájl bekerül a dumpba.
