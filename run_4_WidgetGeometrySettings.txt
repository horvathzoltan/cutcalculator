🎯 Bevezetés

A CutCalculator UI‑állapotkezelése egy monitorprofil‑alapú snapshot
rendszerre épül, amelyet egy fallback baseline egészít ki.
A cél:

-   a felhasználó UI‑elrendezése mindig visszaálljon
-   monitorváltáskor is stabil maradjon
-   ne legyen többé 15px splitter
-   minden művelet auditálható legyen
-   a rendszer önmagát gyógyítsa, ha valami túl korán futna

A megoldás három fő pilléren áll:

-   SnapshotManager – monitorprofilhoz kötött snapshotok
-   LayoutDefaultStore – settings.ini fallback baseline
-   GeometryHelper – percent‑based számítások és deferred restore

------------------------------------------------------------------------

📋 Követelményspecifikáció

✅ 1. Ablak geometriák

-   Mentés százalékban: x%,y%,w%,h%
-   Visszaállítás az aktuális képernyőméretre skálázva
-   Monitorprofilhoz kötött snapshot
-   Restore csak akkor fusson, ha a widget geometry‑ready

✅ 2. Splitter állapotok

-   Mentés arányosan: 70.0%,30.0%
-   Több gyerek esetén lista: 50.0%,30.0%,20.0%
-   Restore deferred, ha a splitter túl kicsi (<50px)
-   Drift korrekció

✅ 3. Header állapotok

-   Oszlopszélességek százalékos mentése
-   Deferred restore, amíg a parent width stabil

✅ 4. Monitorprofil kezelés

-   Formátum: WIDTHxHEIGHT_DPI
-   Snapshot fájlok külön profilhoz kötve
-   DPI és felbontás változás kezelése

✅ 5. Fallback baseline értékek

-   settings.ini tárolja:
    -   window geometry
    -   screen size
    -   main splitter
    -   left vertical splitter
    -   right vertical splitter
    -   product types splitter
    -   product tree header
-   LayoutDefaultStore kezeli

✅ 6. Audit log

-   Minden művelet explicit logolva:
    -   ✅ mentés
    -   ✅ visszaállítás
    -   ⚠️ halasztás
    -   ⚠️ invalid state
    -   📺 screen change

------------------------------------------------------------------------

⚙️ Funkcionális specifikáció

🧠 Mentési folyamat

🪟 Ablak

1.  GeometryHelper → percent string
2.  SnapshotManager → snapshot fájl
3.  LayoutDefaultStore → fallback settings.ini

🧩 Splitter

1.  sizes() → percent lista
2.  fallback mentés
3.  snapshot mentés

📊 Header

1.  sectionSize(i) → percent lista
2.  fallback + snapshot

------------------------------------------------------------------------

🔄 Visszaállítási folyamat

🪟 Ablak

1.  SnapshotManager → snapshot keresése
2.  Ha nincs → fallback
3.  GeometryHelper → deferred restore
4.  Screen change log

🧩 Splitter

1.  snapshot vagy fallback
2.  percent → pixel
3.  drift korrekció
4.  deferred restore

📊 Header

1.  snapshot vagy fallback
2.  deferred restore

------------------------------------------------------------------------

🖥️ Monitorprofil logika

-   Snapshotok monitorprofilhoz kötöttek
-   Új monitor → új snapshot
-   DPI/felbontás változás → új profil
-   Fallback baseline változatlan marad

------------------------------------------------------------------------

🛠️ Implementációs terv

✅ Modulok

📦 GeometryHelper

-   stateless
-   percent‑based számítások
-   deferred restore
-   drift korrekció
-   audit log

📦 LayoutDefaultStore

-   settings.ini fallback baseline
-   singleton
-   flush()

📦 SnapshotManager

-   monitorprofil
-   snapshot path
-   window snapshot
-   workbench snapshot
-   audit log

📦 WorkbenchSnapshot

-   egyszerű struct
-   4 mező: leftVertical, productTypes, rightVertical, treeHeader

📦 MainWindow

-   window snapshot restore/save
-   fallback restore/save
-   splitter fallback

📦 BOMWorkbench

-   splitter snapshot + fallback
-   header snapshot + fallback
-   deferred restore

🔄 Folyamatok

🚀 Startup

1.  MainWindow::showEvent → QtEventUtil::post
2.  SnapshotManager::restoreWindowSnapshot
3.  fallback restore
4.  splitter restore
5.  BOMWorkbench::restoreState

🛑 Shutdown

1.  MainWindow::closeEvent
2.  fallback mentés
3.  BOMWorkbench::saveState
4.  snapshot mentés
5.  flush
